# 로드맵

## 완료된 항목

- 역할 카드 공개 애니메이션과 결과 화면의 마지막 투표 집계 시각화
- 단계 전환·탈락·게임 종료 효과음 및 켜기/끄기 설정
- 게임 전체 동작 줄이기 설정과 즉시 대화 스크롤
- XP, 레벨, 칭호, 최근 플레이 기록과 업적 저장
- 업적 판정·알림·통계 연결, 진영 기준 승률과 결과 공유
- 상세 결과 카드, 투표 요약, 전체 로그 보기 및 텍스트 내보내기
- 하루 1회 보너스를 제공하는 오늘의 사건 모드와 고난도 사건
- 채팅 플랫폼 응답 미리보기
- 가상 참가자의 익명 이름, 성격별 대사와 투표 패턴
- 가상 참가자 간 신뢰도와 투표 로직 반영
- 일반 게임 난이도 선택과 모바일 설정 화면 개선
- 규칙 엔진 상태·대상 명령 타입과 역할 구성·승패·행동 대상 검증 분리
- 탈락 후 행동·투표 없이 남은 결과 진행
- 밤·투표 일괄 판정 및 신뢰도·승패·기여 계산의 순수 함수 분리
- 중복 결과 실행 방지와 최종 단계 로그 보존
- 참가자별 화면 데이터 투영, 공개·개인 로그 구분 및 본인 관점 완료 기록
- 공급자 중립 대사 입력·요청 조정기와 테스트 전용 가짜 공급자 검증(현재 게임 화면 미연결)

- 공급자 중립 게임별 예산 예약과 토큰·요청 수·금액 상한 검증
- 조정기·예산·공급자 준비/생성 연결, 계산 중 취소·단계 변경 차단(공개 API·UI 미연결)
- 선택형 OpenAI HTTP 어댑터: 입력 토큰 조회·출력 상한·구조화 응답·키 미설정 비활성·모의 HTTP 검증

## 다음 작업

[v2 구현 계획](./v2-implementation-plan.md)에 현재 구조, 단계별 범위와 완료 기준을 정리했습니다. 작업 단위 A~D·E1 예산 예약·E2 공통 호출 경로와 선택형 OpenAI HTTP 어댑터의 코드·테스트를 완료했으며 실제 AI·UI 연결과 B·C의 브라우저 한 판 확인은 남아 있습니다. 다음 구현은 아래 순서로 진행합니다.

1. E2: 운영 공급자·모델·단가·예산 확정 및 실제 API 품질·지연 평가, 인증·영속 요청/예산 저장소·서버 대사 API·UI 연결
2. 서버가 판정하는 비공개 방과 규칙 기반 NPC 혼합 모드

효과음 청음과 데스크톱·모바일 실제 화면 검증은 미완료입니다. 개발 환경의 브라우저 연결이 가능해지면 별도로 확인합니다.

## 나중에 검토할 것

- 연쇄살인마·교주 등 신규 역할과 다중 진영 승리 조건
- 결과 리포트 이미지 내보내기
- 서버 저장소와 계정 연동, 서버 검증 보상
- 공개 매칭과 랭킹
- 운영자용 밸런스 설정 및 대화 템플릿 관리 화면

LLM 공급자·모델, 실시간 전송 수단과 저장소는 아직 미선정입니다. 도입 시 품질·비용·배포 환경을 검증합니다.
