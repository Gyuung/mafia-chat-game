# 로드맵

## 완료된 항목

- 역할 카드 공개 애니메이션과 결과 화면의 마지막 투표 집계 시각화
- 단계 전환·탈락·게임 종료 효과음 및 켜기/끄기 설정
- 게임 전체 동작 줄이기 설정과 즉시 대화 스크롤
- XP, 레벨, 칭호, 최근 플레이 기록과 업적 저장
- 업적 판정·알림·통계 연결, 진영 기준 승률과 결과 공유
- 상세 결과 카드, 투표 요약, 전체 로그 보기 및 텍스트 내보내기
- 하루 1회 보너스를 제공하는 오늘의 사건 모드와 고난도 사건
- 채팅 플랫폼 응답 미리보기
- 가상 참가자의 익명 이름, 성격별 대사와 투표 패턴
- 가상 참가자 간 신뢰도와 투표 로직 반영
- 일반 게임 난이도 선택과 모바일 설정 화면 개선

## 다음 작업

[v2 구현 계획](./v2-implementation-plan.md)에 현재 구조, 단계별 범위와 완료 기준을 정리했습니다. 계획 수립은 완료했으며 기능 구현은 아래 순서로 진행합니다.

1. 순수 규칙 엔진의 상태·명령 타입과 승패·대상 검증 분리
2. 밤·투표 판정 분리와 기존 솔로 게임 연결
3. 참가자별 공개 상태와 개인 로그 분리
4. 선택형 LLM 대사 어댑터와 실패 시 기존 대사 반환
5. 서버가 판정하는 비공개 방과 규칙 기반 NPC 혼합 모드

효과음 청음과 데스크톱·모바일 실제 화면 검증은 미완료입니다. 개발 환경의 브라우저 연결이 가능해지면 별도로 확인합니다.

## 나중에 검토할 것

- 연쇄살인마·교주 등 신규 역할과 다중 진영 승리 조건
- 결과 리포트 이미지 내보내기
- 서버 저장소와 계정 연동, 서버 검증 보상
- 공개 매칭과 랭킹
- 운영자용 밸런스 설정 및 대화 템플릿 관리 화면

LLM 공급자·모델, 실시간 전송 수단과 저장소는 아직 미선정입니다. 도입 시 품질·비용·배포 환경을 검증합니다.
