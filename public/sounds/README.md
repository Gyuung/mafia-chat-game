# 게임 효과음

2026-11-10 Codex가 이 프로젝트용으로 직접 합성한 음원입니다. 외부 음원이나 샘플을 사용하지 않았습니다.

- 포맷: 22,050 Hz, 16-bit PCM, 모노 WAV
- 합성: 사인파에 12 ms 어택과 제곱 감쇠 적용, 음마다 160 ms
- 주파수(Hz): 밤 220/165/110, 낮 330/440/554, 투표 440/440, 탈락 150/100/65, 종료 330/440/554/660
- 재생 음량: 35%. 효과음 기본값은 꺼짐이며 설정은 페이지를 새로 열면 초기화됩니다.

`SoundControl`에서 단계 전환 및 탈락 이벤트에 맞춰 재생합니다. 종료와 탈락이 동시에 발생하면 종료음을 우선합니다.
